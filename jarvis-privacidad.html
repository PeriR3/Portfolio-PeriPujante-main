Jarvis — Política de privacidad

Última actualización: 7 de noviembre de 2026

Jarvis es un asistente personal de uso privado creado y utilizado únicamente por Peri Pujante en su propio ordenador. No es un servicio público y no está disponible para otras personas.

Datos a los que accede

Con la autorización expresa de su propietario, Jarvis accede a Google Calendar (permiso https://www.googleapis.com/auth/calendar) para consultar, crear, modificar o eliminar eventos a petición del propio usuario.

Cómo se usan y almacenan

Los datos del calendario se usan solo para responder a las peticiones del usuario. Los tokens de acceso se guardan de forma local en el ordenador del usuario. Jarvis no tiene servidores propios, no vende ni comparte datos con terceros y no los usa con fines publicitarios.

Uso de datos de las API de Google

El uso que hace Jarvis de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
